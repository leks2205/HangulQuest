# 한글 탐험 · Hangul Quest

마인크래프트를 하면서 한국어를 배우는 모드예요.

- 퀘스트 문장이 한국어로 나와요. 문장에 나온 블록을 놓거나 캐면 퀘스트가 끝나요.
- 어려운 문장은 더 쉬운 한국어 힌트로 도와줘요.
- 퀘스트 길이 420개 있어요. 쉬운 길에서 시작해서 점점 어려워져요.
- 서버도 인터넷 연결도 필요 없어요. 정보를 밖으로 보내지 않아요.

설치 방법과 사용법은 [영어 설명서](https://leks2205.github.io/HangulQuest/)와 [README](README.md)에 있어요.

## 한국어를 잘하시는 분께

게임에 나오는 한국어 문장이 자연스러운지 봐 주세요. 한국어가 모국어인 분이나 한국어를 아주 잘하시는 분, 한국어 선생님이면 큰 도움이 돼요.

1. [리뷰 사이트](https://leks2205.github.io/HangulQuest/review/)를 열어요.
2. 문장을 읽어요.
3. 자연스러우면 **맞아요**, 어색하면 **고치기 제안**을 눌러요.

GitHub 계정만 있으면 되고, 따로 설치할 것은 없어요. 자세한 방법은 [검토 안내서](docs/review/README.ko.md)를 봐 주세요. 도와 주신 분의 이름은 [크레딧](https://leks2205.github.io/HangulQuest/credits.html)에 올려요.

이 소개문도 어색한 곳이 있으면 [여기](https://github.com/leks2205/HangulQuest/issues/new?template=korean-general.yml&title=%5BKorean%5D+question%3A+README.ko)에 알려 주세요.
