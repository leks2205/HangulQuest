# Help review Korean

Every Korean line in the game, from a quest clue to a word card, is checked by a linter and by two AI
reviewers. Only a person who speaks Korean can say that a line sounds natural. If you do, you can help
without installing anything and without using git.

**[Open the review site](review/index.html)** (it is in Korean first, then English).

1. Open a page and read the lines.
2. Press **맞아요 / Looks right** when a line is natural.
3. Press **고치기 제안 / Suggest a correction** when it is wrong or odd, and write the better line.

Each button opens a prefilled GitHub form; you need a GitHub account. A bot checks the line id, the
text and the Korean linter, then a maintainer decides. Approvals count from accounts at least 30 days
old, and nobody can approve their own line. A line becomes *native approved* after two different
reviewers approve it, or one trusted reviewer.

Your name goes on the [credits](credits.md) page, unless you write `anonymous` in the form.

The full rules for reviewers (and the Korean guide) are in
[CONTRIBUTING.md](https://github.com/leks2205/HangulQuest/blob/main/CONTRIBUTING.md#help-review-korean).
