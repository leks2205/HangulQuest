# 한국어 문장 검토 안내

> **이 안내문도 아직 어색할 수 있어요.** 한국어가 모국어이신 분이 더 자연스럽게 고쳐 주시면 정말 고맙겠어요.
> [여기에 의견을 남겨 주세요.](https://github.com/leks2205/HangulQuest/issues/new?template=korean-general.yml&title=%5BKorean%5D+question%3A+review+guide)

한글 탐험은 마인크래프트를 하면서 한국어를 배우는 모드예요. 게임에 나오는 한국어 문장을 한국어를 잘하시는 분이 읽어 주시면 큰 도움이 돼요. 문장은 짧고 쉬워요. 5분이면 충분해요.

git이나 코드는 몰라도 돼요.

## 세 단계

1. **리뷰 사이트를 열어요.**
   [leks2205.github.io/HangulQuest/review](https://leks2205.github.io/HangulQuest/review/)
   쉬운 레벨의 문장부터 보여 줘요.
2. **문장을 읽어요.**
   한국어 문장이 크게 보이고, 그 밑에 영어 뜻이 있어요. 영어를 몰라도 괜찮아요. 한국어 문장만 보고 자연스러운지 말해 주세요.
3. **버튼을 눌러요.**
   - 자연스러우면 **맞아요**
   - 어색하거나 틀리면 **고치기 제안**을 누르고, 어떻게 고치면 좋을지 적어요.
   - 한 페이지의 문장을 모두 읽었고 모두 괜찮으면 **이 페이지 전체 승인**

버튼을 누르면 GitHub 양식이 열려요. 미리 채워진 칸은 그대로 두세요. 한국어 실력을 고르고, 맨 아래 칸에 체크한 다음 초록색 **Submit new issue** 버튼을 누르면 끝이에요.

## GitHub 계정

계정이 없으면 [github.com](https://github.com)에서 무료로 만들 수 있어요. 이메일만 있으면 돼요.

- 만든 지 30일이 지난 계정의 승인만 세어요.
- 자기가 쓴 문장은 승인할 수 없어요.
- 문장 하나는 서로 다른 두 분이 승인하면 **원어민 승인**이 돼요.

## 무엇을 봐 주시면 되나요?

- 조사가 맞는지: 을/를, 이/가, 은/는, 에/에서, (으)로
- 동사와 목적어가 잘 어울리는지: 돌을 **캐요**, 꽃을 **꺾어요**, 나무를 **심어요**
- 개수를 세는 말: 한 개, 두 마리, 세 명
- 말투가 같은지: 모두 해요체(…해요)로 써요.
- 띄어쓰기와 자연스러움: 한국 사람이 이렇게 말할까요?
- 마인크래프트 이름: 게임 안의 한국어 이름과 같은지

## 자주 묻는 질문

**잘 모르겠어요.**
그럼 건너뛰어도 돼요. 확실하지 않을 때는 누르지 말아 주세요.

**제 이름이 공개돼요?**
GitHub 양식은 공개되어서 GitHub 이름이 보여요. 크레딧에는 양식의 "크레딧에 쓸 이름" 칸에 적은 이름이 나와요. 이름을 빼고 싶으면 그 칸에 `anonymous`라고 적어 주세요.

**제가 고친 문장이 바로 게임에 들어가요?**
아니요. 먼저 로봇이 확인하고, 마지막은 관리자가 정해요. 고쳐진 문장은 다음 버전에 들어가요.

**한국어를 배우는 중인데 도와도 돼요?**
좋아요! 의견은 언제든 환영해요. 다만 학습자의 승인은 숫자에 세지 않아요.

**한국어 안내문이 어색해요.**
이 안내문부터 고쳐 주세요. 위에 있는 링크로 알려 주시면 돼요.
